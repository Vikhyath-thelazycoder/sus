## What was built

| Task | Built |

| T-5.1 Tokens | Every DESIGN.md colour, type step, radius and layout width is a CSS variable mapped into Tailwind (`index.css`). Raw HTML shows as text, images are dropped, links keep only their label, and `[n]` turns into a citation button (only for sources that exist). **Below each answer:** sources row, copy button, thumbs up/down (saved via `POST /api/messages/:id/feedback`, owner-scoped, migration 0002), and the disclaimer. |

## Accessibility (T-5.6)

**Contrast**, computed for every token pair:
- Text, muted and danger pass 4.5:1 on page, surface and the soft accent, in both themes. The lowest is muted on soft accent: 4.54 (light), 4.74 (dark).
- **Finding:** in light mode the sage accent is **4.22:1** on the page (4.48 on surface). That is below 4.5 for text, though fine for icons and focus rings (≥ 3:1). Rather than change the approved accent, the fix removes it from all small text:
  - the DOI link is body-colour text with an accent underline;
  - source numbers are soft-accent pills;
  - the citation pill's hover is an outline instead of text on the accent.
  DESIGN.md now records this rule.
- **Finding:** `--border` is 1.2–1.3:1, which is fine for dividers but fails WCAG 1.4.11 where a border is what identifies a control. A new **`--control-border`** token (`#8C877A` light, `#6E736B` dark; 3.4–3.7:1) now outlines the question box, suggestions, source chips and buttons. It is added to DESIGN.md.

**Other checks:**
- Every icon button has an `aria-label`.
- The question field has a label.
- One `aria-live` region announces "Searching papers…", "Writing…", "Answer ready." and the error copy.
- Focus rings are visible in the accent colour.
- `prefers-reduced-motion` turns off all animation.
- Touch targets are ≥ 44 px, except the inline `[n]` pills, which are covered by WCAG 2.5.8's inline exception; the sources row offers the same action at full size.

No screen-reader run was done. VoiceOver and NVDA testing is open for P8.

## Data finding (for the ingestion owner)

The live check's top citation was a **"Front matter" chunk**: editor names, a correspondence email address and journal boilerplate. **57 of the 881 chunks (6.5%) across all 20 papers** are front matter. They compete with real content in retrieval, and they bring personal contact details into the source panel. The data is CC BY, but the details are not useful to readers.

**Recommendation:** skip or trim front matter at ingestion, but keep the abstract. The photoredox paper parses entirely as front matter, so it needs a parser fix first. Then re-ingest and re-run both evals.
